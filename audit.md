It splits by what's being audited; few firms cover code, pipeline and team process equally well.

**Security code audits (deep manual review)**
- Trail of Bits, NCC Group, Bishop Fox, Cure53, IOActive, Doyensec

**Whole-SDLC and controls audits (dev to production)**
- Deloitte, PwC, EY, KPMG and Accenture: change management, access, release controls, SOC 2 and Sarbanes-Oxley IT audits
- These assess process and evidence more than code quality

**Code quality and technical due diligence**
- Software Improvement Group (SIG), CAST, Crosslake, and Black Duck (formerly Synopsys's software unit): maintainability, architecture, open-source license and dependency risk, often for acquisitions

**Pipeline and supply-chain security (mostly tooling)**
- Snyk, Veracode, Checkmarx, SonarSource, GitHub Advanced Security, GitLab: scanning built into CI/CD
- Sonatype, JFrog, Chainguard: dependencies, artifacts and build provenance

**Engineering process and collaboration**
- Thoughtworks and similar consultancies do delivery and DevOps maturity assessments, often using DORA metrics (deploy frequency, lead time, failure rate, recovery time)

The standards these audits measure against are NIST's Secure Software Development Framework, SLSA for build integrity, and OWASP SAMM for maturity. An end-to-end audit usually means pairing a security boutique for the code with a process assessment against one of those frameworks.

This is from general knowledge, not a fresh lookup, so check current offerings before shortlisting anyone.
